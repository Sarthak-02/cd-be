🎯 Event Management · Attendee Engagement

TribePing

A full-stack conference app for organizers and participants. Real-time messaging, live session tracking, push notifications, and bulk attendee management — all in one installable PWA.

  • Live session indicator — auto-highlights the currently running session
  • Real-time peer-to-peer messaging powered by Firebase Firestore
  • push notifications that work even when app is closed
  • Participant directory with one-tap direct messaging
  • Bulk CSV user import — onboard hundreds of attendees at once
  • Multi-event support — one account, many events
  • Admin portal: event creation, schedule management, analytics
